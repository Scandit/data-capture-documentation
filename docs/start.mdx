# Not sure which Scandit product? Start here

The home page's platform picker assumes you already know your product. This is the other
axis — **pick your intent, get the product** — for the cross-product confusion the replay
and ticket data shows (SparkScan vs Barcode Capture, ID Capture vs ID Bolt…). It is driven
by **one shared intent taxonomy**, the same scan type → task → product map the sign-up quiz
uses, so the docs and sign-up recommend the **same product**. Each recommendation links to
that product's docs for your platform.
