ID Bolt is a hosted identity scanning solution that enables you to provide customers a fast, foolproof ID scanning in just 1 second, leading to an improved customer experience as well as compliance. Scandit hosts the scanning UI and keeps it up to date. The scanning itself runs on the user's device, in the browser, on desktop and mobile alike. Scandit's servers never see identity data in readable form, and on-device scanning reduces latency for quick scanning performance.

:::tip
In addition to ID Bolt, Scandit provides an [ID Capture SDK for the Web](/sdks/web/id-capture/intro.md) that allows full flexibility around the user interface and user flow.
:::

## Features

ID Bolt offers the following features:

- **Fast Scanning**: ID Bolt scans an ID in just 1 second. Scans are performed from video streams for the fastest possible scanning.
- **On-Device Scanning/Processing**: ID Bolt scans IDs on the user's device, in the browser. Scandit's servers never see identity data in readable form, and processing on the device improves performance.
- **Device Handover**: ID Bolt works on both desktop and mobile devices, providing a unified solution. Desktop/laptop users can scan IDs using their mobile device camera. The handover goes through Scandit's relay, end-to-end encrypted.
- **Industry Leading UX**: ID Bolt presents a simple, intuitive interface, designed based on the millions of scans performed by Scandit customers each year.
- **Compliance**: ID Bolt ensures compliance with data protection regulations, such as GDPR, by scanning on the device. Scandit's servers never see identity data in readable form, including during device handover.
- **White-Label Solution**: ID Bolt can be placed behind your own domain, allowing you to maintain brand consistency and provide an integrated experience to your customers while leveraging Scandit's powerful ID scanning capabilities.
