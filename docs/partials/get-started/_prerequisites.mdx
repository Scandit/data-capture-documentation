You need:

- A valid Scandit Data Capture SDK license key.
- The Scandit Data Capture SDK added to your project, including the required camera permissions. If you haven't done this yet, follow <Link to={`/sdks/${props.framework}/add-sdk`}>Add the SDK</Link>.
- A physical device with a camera. The scanner uses the camera, so it doesn't run on a simulator or emulator.

:::tip
Get your license key by signing in to your [Scandit dashboard](https://ssl.scandit.com/dashboard/sign-in).
:::
