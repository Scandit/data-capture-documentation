Shipping Label Scanning reads a shipping label and returns its tracking ID, the receiver's name and address, and the carrier. Like receipt scanning, it uses the Adaptive Recognition Engine, which processes the label in the cloud.

To read your own set of fields on the device instead, define a <DocLink framework={props.framework} page="label-definitions">custom label</DocLink>.

:::warning Beta
Shipping Label Scanning requires the Adaptive Recognition Engine, which is still in beta and may change in future versions of Scandit Data Capture SDK. To enable it on your subscription, contact [support@scandit.com](mailto:support@scandit.com).
:::

## Before you start

- Use Scandit Data Capture SDK 8.6.0 or later. Shipping Label Scanning is available on iOS, Android, and Web. It isn't available on other frameworks yet.
- Ask [support@scandit.com](mailto:support@scandit.com) to enable the Adaptive Recognition Engine on your subscription.
- Set up a `LabelCapture` instance and a `DataCaptureView`. If you haven't done this yet, follow <DocLink framework={props.framework} page="get-started">Get started</DocLink>.
- Make sure the device has a network connection. The Adaptive Recognition Engine processes the label in the cloud.

## Steps

1. Create <ApiLink framework={props.framework} page={settingsPage} anchor={`class-${settingsAnchor}`}>LabelCaptureAdaptiveRecognitionSettings</ApiLink> with the result type <ApiLink framework={props.framework} page={resultTypePage} anchor="value-scandit.datacapture.label.AdaptiveRecognitionResultType.ShippingLabel">{symbolTokens[props.framework].shippingLabel}</ApiLink>. The result type sets the kind of document that the overlay looks for.

   <Only when={props.framework === 'web'}>

   `create()` is asynchronous. If you call it without a result type, it creates settings for receipts.

   </Only>

   To change the hint that the overlay shows while it processes a label, use <ApiLink framework={props.framework} page={settingsPage} anchor={symbolTokens[props.framework].processingHintAnchor}>{symbolTokens[props.framework].processingHint}</ApiLink>.

   <Only when={props.framework === 'android'}>

   ```kotlin
   import com.scandit.datacapture.label.ui.overlay.adaptiverecognition.AdaptiveRecognitionResult
   import com.scandit.datacapture.label.ui.overlay.adaptiverecognition.AdaptiveRecognitionResultType
   import com.scandit.datacapture.label.ui.overlay.adaptiverecognition.LabelCaptureAdaptiveRecognitionListener
   import com.scandit.datacapture.label.ui.overlay.adaptiverecognition.LabelCaptureAdaptiveRecognitionOverlay
   import com.scandit.datacapture.label.ui.overlay.adaptiverecognition.LabelCaptureAdaptiveRecognitionSettings
   import com.scandit.datacapture.label.ui.overlay.adaptiverecognition.ShippingLabelScanningResult

   val settings = LabelCaptureAdaptiveRecognitionSettings.newInstance(
       AdaptiveRecognitionResultType.SHIPPING_LABEL
   )
   ```

   </Only>

   <Only when={props.framework === 'ios'}>

   ```swift
   import ScanditLabelCapture

   let settings = LabelCaptureAdaptiveRecognitionSettings(resultType: .shippingLabel)
   ```

   </Only>

   <Only when={props.framework === 'web'}>

   ```ts
   import {
     AdaptiveRecognitionResultType,
     LabelCaptureAdaptiveRecognitionOverlay,
     LabelCaptureAdaptiveRecognitionSettings,
     ShippingLabelScanningResult,
     type AdaptiveRecognitionResult,
   } from "@scandit/web-datacapture-label";

   const settings = await LabelCaptureAdaptiveRecognitionSettings.create(
     AdaptiveRecognitionResultType.ShippingLabel
   );
   ```

   </Only>

2. Create the overlay with <ApiLink framework={props.framework} page={overlayPage} anchor={`method-${overlayAnchor}.NewInstance`}>{symbolTokens[props.framework].overlayCreate}</ApiLink>. Then apply the settings with <ApiLink framework={props.framework} page={overlayPage} anchor={`method-${overlayAnchor}.ApplySettings`}>{symbolTokens[props.framework].applySettings}</ApiLink>.

   When you pass your `DataCaptureView`, the overlay adds itself to the view. {symbolTokens[props.framework].noView}, add the overlay yourself with <code>{symbolTokens[props.framework].addOverlay}</code>.

   <Only when={props.framework === 'android'}>

   ```kotlin
   private lateinit var overlay: LabelCaptureAdaptiveRecognitionOverlay

   overlay = LabelCaptureAdaptiveRecognitionOverlay.newInstance(
       requireContext(),
       labelCapture,
       dataCaptureView,
   )
   overlay.applySettings(settings)
   ```

   </Only>

   <Only when={props.framework === 'ios'}>

   ```swift
   let overlay = LabelCaptureAdaptiveRecognitionOverlay(labelCapture: labelCapture, view: dataCaptureView)
   overlay.apply(settings)
   ```

   </Only>

   <Only when={props.framework === 'web'}>

   ```ts
   const overlay = await LabelCaptureAdaptiveRecognitionOverlay.withLabelCaptureForView(
     labelCapture,
     dataCaptureView
   );
   await overlay.applySettings(settings);
   ```

   </Only>

3. Set a <ApiLink framework={props.framework} page={listenerPage} anchor={`interface-${listenerAnchor}`}>{symbolTokens[props.framework].listener}</ApiLink> as the overlay's <ApiLink framework={props.framework} page={overlayPage} anchor={`property-${overlayAnchor}.Listener`}>{symbolTokens[props.framework].listenerProperty}</ApiLink>. It receives two callbacks:

   - <ApiLink framework={props.framework} page={listenerPage} anchor={`method-${listenerAnchor}.OnRecognized`}>{symbolTokens[props.framework].onRecognized}</ApiLink> runs when the label is recognized. Check that the result is a <ApiLink framework={props.framework} page={resultPage} anchor="class-scandit.datacapture.label.ShippingLabelScanningResult">ShippingLabelScanningResult</ApiLink>, then read its fields.
   - <ApiLink framework={props.framework} page={listenerPage} anchor={`method-${listenerAnchor}.OnFailure`}>{symbolTokens[props.framework].onFailure}</ApiLink> runs when a connection error occurs during recognition.

   <Only when={props.framework === 'ios'}>

   The overlay holds its delegate weakly, so keep a strong reference to the delegate object.

   </Only>

   <Only when={props.framework === 'android'}>

   ```kotlin
   overlay.listener = object : LabelCaptureAdaptiveRecognitionListener {
       override fun onRecognized(result: AdaptiveRecognitionResult) {
           val shippingLabel = result as? ShippingLabelScanningResult ?: return

           val trackingId = shippingLabel.trackingId
           val receiverName = shippingLabel.receiverFullName
           val receiverCompany = shippingLabel.receiverCompany // null if the label doesn't show one
           val carrier = shippingLabel.carrier
       }

       override fun onFailure() {
           // A connection error occurred while recognizing the label.
       }
   }
   ```

   </Only>

   <Only when={props.framework === 'ios'}>

   ```swift
   overlay.delegate = self

   extension YourScanViewController: LabelCaptureAdaptiveRecognitionDelegate {
       func labelCaptureAdaptiveRecognitionOverlay(_ overlay: LabelCaptureAdaptiveRecognitionOverlay,
                                                   didRecognizeWith result: AdaptiveRecognitionResult) {
           guard let shippingLabel = result as? ShippingLabelScanningResult else { return }

           let trackingId = shippingLabel.trackingId
           let receiverName = shippingLabel.receiverFullName
           let receiverCompany = shippingLabel.receiverCompany // nil if the label doesn't show one
           let carrier = shippingLabel.carrier
       }

       func labelCaptureAdaptiveRecognitionOverlayDidFail(_ overlay: LabelCaptureAdaptiveRecognitionOverlay) {
           // A connection error occurred while recognizing the label.
       }
   }
   ```

   </Only>

   <Only when={props.framework === 'web'}>

   ```ts
   overlay.listener = {
     onRecognized: (result: AdaptiveRecognitionResult) => {
       if (!(result instanceof ShippingLabelScanningResult)) {
         return;
       }

       const trackingId = result.trackingId;
       const receiverName = result.receiverFullName;
       const receiverCompany = result.receiverCompany; // null if the label doesn't show one
       const carrier = result.carrier;
     },
     onFailure: () => {
       // A connection error occurred while recognizing the label.
     },
   };
   ```

   </Only>

<Only when={props.framework === 'android'}>

4. Forward your Activity or Fragment lifecycle to the overlay. Call <ApiLink framework={props.framework} page={overlayPage} anchor={`method-${overlayAnchor}.OnResume`}>onResume()</ApiLink> in your `onResume` method to start or restore scanning. Call <ApiLink framework={props.framework} page={overlayPage} anchor={`method-${overlayAnchor}.OnPause`}>onPause()</ApiLink> in your `onPause` method to pause it.

   ```kotlin
   override fun onResume() {
       super.onResume()
       overlay.onResume()
   }

   override fun onPause() {
       overlay.onPause()
       super.onPause()
   }
   ```

</Only>

<Only when={props.framework === 'web'}>

While the overlay processes a label, it switches the camera to standby. If recognition fails, the overlay shows an error notification and switches the camera back on.

</Only>

### Handle missing values

- <Field framework={props.framework} name="receiverCompany" anchor="ReceiverCompany"/>, <Field framework={props.framework} name="receiverState" anchor="ReceiverState"/>, and <Field framework={props.framework} name="receiverCountry" anchor="ReceiverCountry"/> are <code>{symbolTokens[props.framework].unset}</code> when the label doesn't show them. Check for <code>{symbolTokens[props.framework].unset}</code> before you use them.
- <Field framework={props.framework} name="carrier" anchor="Carrier"/> is <CarrierValue framework={props.framework} id="Other"/> when the engine recognizes a carrier that isn't in the list below. It's <CarrierValue framework={props.framework} id="NotAvailable"/> when the carrier isn't reported or can't be recognized.
- <Field framework={props.framework} name="barcodes" anchor="Barcodes"/> is always empty in SDK 8.6. Use <Field framework={props.framework} name="trackingId" anchor="TrackingId"/> to get the tracking identifier.

## Verify it works

You're done when:

- The overlay shows its processing hint after you point the camera at a shipping label.
- Your <ApiLink framework={props.framework} page={listenerPage} anchor={`method-${listenerAnchor}.OnRecognized`}>{symbolTokens[props.framework].onRecognized}</ApiLink> callback receives a `ShippingLabelScanningResult`, and you can read its `trackingId` and `carrier`.

If <ApiLink framework={props.framework} page={listenerPage} anchor={`method-${listenerAnchor}.OnFailure`}>{symbolTokens[props.framework].onFailure}</ApiLink> runs instead, check the device's network connection.
