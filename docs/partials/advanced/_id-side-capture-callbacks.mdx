### Receive a result after each side

By default, when ID Capture scans a double-sided document, it calls <ApiLink framework={props.framework} page={listenerPage} anchor={`${listenerMethod}OnIdCaptured`}>{symbolTokens[props.framework].onCaptured}</ApiLink> only after document recognition is complete. To receive a result after the front side and another after the back side, set <ApiLink framework={props.framework} page={settingsPage} anchor={`${settingsProperty}NotifyOnSideCapture`}>IdCaptureSettings.notifyOnSideCapture</ApiLink> to `true`. Your app then gets partial results even if the back-side scan fails. The default is `false`.

To tell a partial result from a complete one, read <ApiLink framework={props.framework} page={capturedIdPage} anchor={`${capturedIdProperty}IsCapturingComplete`}>CapturedId.isCapturingComplete</ApiLink>:

- `true`: ID Capture has captured all sides of a multi-sided document, or the document has a single side.
- `false`: Only partial data is available, for example, the front side of a two-sided document.

Both properties are available from SDK version {symbolTokens[props.framework].since}.

The setting takes effect when you create `IdCapture` with these settings, or when you apply them to an existing `IdCapture` with <ApiLink framework={props.framework} page={idCapturePage} anchor={`${idCaptureMethod}ApplySettings`}>{`IdCapture.${symbolTokens[props.framework].applySettings}`}</ApiLink>.

```kotlin
# import com.scandit.datacapture.id.capture.IdCaptureListener
# import com.scandit.datacapture.id.capture.IdCaptureSettings
# import com.scandit.datacapture.id.data.CapturedId
# val settings = IdCaptureSettings()

idCapture.applySettings(settings)

# object : IdCaptureListener {

    if (capturedId.isCapturingComplete) {

        // Partial result, for example, the front side of a two-sided document.
    }
}
# }
```

<Only when={props.framework === 'web'}>

```ts
import { type CapturedId } from "@scandit/web-datacapture-id";

settings.notifyOnSideCapture = true;
await idCapture.applySettings(settings);

idCapture.addListener({
  didCaptureId: (capturedId: CapturedId) => {
    if (capturedId.isCapturingComplete) {
      // All sides are captured, or the document has a single side.
    } else {
      // Partial result, for example, the front side of a two-sided document.
    }
  },
});
```

</Only>
